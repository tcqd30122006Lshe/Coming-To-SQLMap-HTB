## 🎯 Mục Tiêu Khóa Học
Khóa học **SQLMap Essentials** cung cấp kiến thức toàn diện từ cơ bản đến nâng cao về công cụ khai thác SQL Injection tự động mạnh mẽ nhất hiện nay - **SQLMap**:
- Nắm vững 6 kỹ thuật SQLi cốt lõi: Boolean-based blind, Error-based, UNION query-based, Stacked queries, Time-based blind, và Inline queries (`BEUSTQ`).
- Chặn bắt và phân tích HTTP Requests để đưa vào SQLMap tự động kiểm thử.
- Tinh chỉnh các tham số kết nối, kỹ thuật tiêm, mức độ mạo hiểm (`--level`, `--risk`), và luồng (`--threads`).
- Khai thác trích xuất dữ liệu: Liệt kê CSDL, bảng, cột, dump mật khẩu băm và giải mã tự động.
- Kỹ thuật nâng cao: Vượt tường lửa ứng dụng web (WAF Bypass) bằng Tamper Scripts và chiếm quyền điều khiển hệ điều hành (`--os-shell`).
